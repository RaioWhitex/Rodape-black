# 🖥️ Footer Section UI

Uma interface moderna de rodapé desenvolvida com foco em organização, elegância e experiência do usuário, utilizando um layout profissional para apresentar informações institucionais, serviços, contatos e redes sociais.

---

## 📸 Preview do Projeto

Interface contendo:

- Seção institucional “About us”
- Área de serviços organizados
- Campo de inscrição para newsletter
- Botão estilizado de envio
- Ícones de redes sociais
- Informações de contato
- Layout moderno e responsivo

---

## ✨ Tecnologias Utilizadas

- **HTML5**
- **CSS3**

---

## 🎨 Características do Design

- Interface moderna e minimalista
- Tema escuro elegante
- Layout dividido em colunas
- Ícones sociais integrados
- Botão de ação destacado
- Estrutura clean e organizada
- Efeitos hover suaves
- Design responsivo

---

## 🚀 Objetivo do Projeto

Praticar habilidades de desenvolvimento front-end através da criação de um rodapé moderno e responsivo, explorando conceitos de organização visual, estilização avançada e componentes reutilizáveis com CSS.

---

## 📚 Funcionalidades

- Exibição de informações institucionais
- Área de serviços organizados
- Campo para inscrição em newsletter
- Links para redes sociais
- Informações de contato
- Estrutura adaptável para diferentes dispositivos
